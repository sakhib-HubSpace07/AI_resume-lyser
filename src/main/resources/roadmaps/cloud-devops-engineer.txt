Cloud DevOps Engineer
[projects]
Static site pipeline (Beginner): Deploy a website on cloud storage with a GitHub Actions pipeline that publishes every push. About 1 week.
Three-tier app on the cloud (Intermediate): Deploy a web app, API and database with Docker and Terraform on a free tier account. About 2 weeks.
Kubernetes deployment with monitoring (Advanced): Run an app on Kubernetes with Helm and add Prometheus and Grafana dashboards. About 3 weeks.
GitOps platform (Advanced): Set up Argo CD so that every change in a Git repository deploys automatically with rollbacks. About 3 weeks.

Tailor your resume: Use the exact skills from real Cloud DevOps Engineer job postings, keep it to one page and show measurable results. About 2 days.
