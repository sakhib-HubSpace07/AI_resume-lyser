AI Agent Engineer
[projects]
Tool-using assistant (Beginner): Build an assistant that calls three tools such as search, calculator and weather using function calling. About 1 week.
Research agent (Intermediate): Build an agent that plans, searches the web and writes a short cited report, with every step traced. About 2 weeks.
Multi-agent workflow (Advanced): Build two or three cooperating agents for one real workflow with LangGraph and add human approval for risky steps. About 3 weeks.
MCP server and agent evaluation (Advanced): Expose one real tool through an MCP server and measure your agent's success rate on 20 test tasks. About 3 weeks.
