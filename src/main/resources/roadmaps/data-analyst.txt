Sales dashboard (Beginner): Clean a public sales dataset in Excel or Python and build an interactive dashboard in Power BI or Tableau. About 1 week.
Customer churn analysis (Intermediate): Use SQL and Python to find why customers leave, test your ideas with statistics and present 3 clear recommendations. About 2 weeks.
A/B test case study (Intermediate): Analyze a public experiment dataset, run hypothesis tests and write a one-page business summary. About 2 weeks.
End-to-end data pipeline (Advanced): Collect data from a public API, clean it with Python, store it in a database and refresh a dashboard automatically. About 3 weeks.
